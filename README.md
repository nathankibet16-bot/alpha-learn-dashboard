# AlphaTrade Dashboard

use the above as your refrence Build a dark-themed cryptocurrency market simulation dashboard called "AlphaGroup" for educational tracking. 

Design a two-step signup screen featuring a progressive step indicator, a success screen, a clean login flow, and a main dashboard view. 

On the main dashboard, include:

1. A top marquee running ticker for crypto market data.

2. A main card displaying "Current Demo Balance".

3. Three quick-action buttons: Top Up Demo, Withdraw Simulation, and Live Charts.

4. Embedded trading charts for BTC, ETH, and SOL using TradingView iframe widgets.

5. A slide-out navigation sidebar with links for Dashboard, Markets, Analysis Logs, and Profile.

Use Tailwind CSS colors: bg-zinc-950 for backgrounds, emerald-500 for success actions and positive gains, and red-500 for negative market movement. Keep all terminology strictly educational and focused on simulation, avoiding any words implying real financial investment or financial advice.
